# College Placement Portal

A full-stack Placement Management System built using Flask, SQLite, HTML, CSS, and JavaScript.

## Features

### Student Features

* Student Registration and Login
* Profile Management
* Upload Profile Photo
* Update Skills
* View Available Jobs
* Search and Filter Jobs
* Save Jobs
* Apply for Jobs
* Upload Resume
* Resume Scoring
* Skill Match Percentage
* Recommended Jobs
* View Applications
* Withdraw Applications
* Interview Scheduling
* Notifications Dashboard
* Dark Mode

### Admin Features

* Admin Login
* Add Jobs
* Edit Jobs
* Delete Jobs
* View Applicants
* Search Applicants
* Filter Applicants
* Update Application Status
* Schedule Interviews
* Export Applicants CSV
* Dashboard Analytics

## Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Flask (Python)
* Database: SQLite
* Version Control: Git & GitHub

## Project Structure

placement-portal/

* static/

## Installation

1. Clone repository

git clone https://github.com/TharunKumar1111/placement-portal.git

2. Move into project directory

cd placement-portal

3. Install dependencies

pip install -r requirements.txt

4. Run application

python app.py

5. Open browser

http://127.0.0.1:5000
